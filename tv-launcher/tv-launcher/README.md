# Мой лаунчер для Android TV

Простой лаунчер: сетка приложений, часы, дата. Управление пультом.

- **OK** — запустить приложение
- **Удерживать OK** — сведения о приложении (удаление, остановка)
- **Меню / Настройки** — системные настройки
- **Назад** — вернуться к началу списка (лаунчер не закрывается)

## Как получить APK (без Android Studio)

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** → **Build APK** → **Run workflow**.
3. Когда сборка закончится, скачайте `tv-launcher-apk` из Artifacts и распакуйте `app-debug.apk`.

Либо откройте папку в Android Studio и нажмите Build → Build APK.

## Как поставить на приставку

1. Скопируйте `app-debug.apk` на флешку и откройте его файловым менеджером приставки
   (например, X-plore) либо установите по сети: `adb connect <IP приставки>` и `adb install app-debug.apk`.
   В настройках должна быть разрешена установка из неизвестных источников.
2. Нажмите кнопку «Домой» на пульте. Система предложит выбрать лаунчер, выберите «Мой лаунчер» → «Всегда».

Если кнопка «Домой» всё равно открывает оболочку KION, а выбор не предлагается, лаунчер можно запускать
как обычное приложение из списка. Вернуть оболочку по умолчанию:
Настройки → Приложения → Показать все → KION → Очистить значения по умолчанию.
